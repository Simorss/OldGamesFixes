# Changelog

## 1.0.0-beta.1

- Interactive game path and resolution selection.
- Original-proportion or full-screen stretched menu/HUD mode.
- Aspect-dependent gameplay focal length with preserved vertical FOV.
- Uniform centered UI scaling on wide, 4:3 and narrow displays.
- Matching inverse UI coordinate mapping and clipping bounds.
- Migration from this project's earlier fixed-3440 patches.
- Persistent first-use backups, integrity checks, preview and restore.
- Windows PowerShell 5.1 entry point with no runtime downloads.

The earlier 3440x1440 gameplay fix was confirmed in-game. The generalized UI
patch and other display modes still require visual playtesting.
