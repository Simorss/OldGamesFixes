**Bonus release · Version 1.0**

**EM4SMD** is a small CMD file that scans the game's `Mods` folder, displays its
subfolders as a numbered list and launches the selected mod directly.

## Usage

1. Download **EM4SMD.cmd** and put it beside **Em4Deluxe.exe** (or in a direct subfolder such as `Lancia`).
2. Double-click the file, type a mod number and press Enter.
3. Enter **0** to close the launcher.

The command used is `Em4Deluxe.exe -game -mod "Selected mod folder"`.
The list refreshes on every run. Windows PowerShell is required; no separate
scripts, ASI plugin or installation are needed. Game files remain unchanged.
