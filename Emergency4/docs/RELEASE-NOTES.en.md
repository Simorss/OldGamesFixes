Configurable resolution and aspect ratio fixes for Emergency 4 Deluxe / Edizione Oro.

- Interactive resolution selection.
- Adjusted horizontal gameplay FOV while preserving the original vertical FOV.
- Menu and HUD options: centered original 4:3 proportions or full-screen stretched scaling.
- Backup, restore, settings changes, and migration from the earlier 3440x1440 fixes.
- Double-click Emergency4-Fix.cmd to start; Python is not required.

Only the Em4Deluxe.exe build identified in the README is supported.
Your chosen resolution must also be supported by the game and your system.

**Beta status:** automated tests cover 24 resolution/mode combinations and 120 emulated hit tests.
The original 3440x1440 gameplay fix has been confirmed in-game. The generalized
interface patch and other resolutions still require visual in-game validation.

Download **Emergency4-ResolutionFix-v1.0.0-beta.1.zip**, extract it completely,
close the game, and run **Emergency4-Fix.cmd**. See the included READMEs for details.
