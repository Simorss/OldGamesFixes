## 📖 About

A collection of **fixes and patches for older games**, aimed at improving compatibility and fixing known bugs on modern systems.

As a bonus, this repo also includes a few **Italian localization/translation patches** 🇮🇹 for some titles.

## 📥 Installation

1. Download the ready-to-use package for your game from [Releases](https://github.com/Simorss/OldGamesFixes/releases).
2. Extract the archive and follow the instructions in the game's specific `README.md`.
3. Enjoy!

---

## 🛠️ Contributing

Contributions are welcome! If you have a fix, patch, or translation to share:

1. Fork the repo
2. Create a new branch (`git checkout -b patch/game-name`)
3. Submit a pull request

Please include the game edition, executable hash and clear reproduction steps.
